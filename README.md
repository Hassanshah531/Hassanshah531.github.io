# Ahmed Hassan Shah — Research & Leadership Portfolio

A personal academic and professional website presenting research, leadership, projects, experience and selected publications. Responsive static HTML, CSS and JavaScript. No build step, API key or paid service is required.

## Publish on GitHub Pages

1. Create a public repository called YOUR-USERNAME.github.io.
2. Extract this ZIP. Upload index.html, styles.css, script.js, .nojekyll and the assets folder directly into the repository root. Upload the extracted files, not the ZIP or an enclosing folder.
3. In Settings → Pages choose Deploy from a branch, main, / (root), then Save.
4. When deployment finishes, open https://YOUR-USERNAME.github.io.

A project repository also works because assets use relative paths. Use the public GitHub Pages address in applications. The existing ChatGPT-hosted preview currently has owner-only access.

## Files and interaction guide

- index.html: content, sections and links.
- styles.css: layout, colors, responsive styles and motion.
- script.js: five selected publications, search, navigation and image previews.
- assets/: all local artwork, fonts, original visual references and PDFs.
- LINK_REVIEW.md: complete destination inventory, click behavior and verification limits.

Project cards enlarge screenshots; they do not launch live demos. Paper rows open Google Scholar records. PDFs open in a new tab. Email launches the visitor’s configured mail app. There is no contact-form backend or automatic email sending.

## Attribution and accuracy

The site distinguishes supplied event photographs and team/company interfaces from conceptual and AI-enhanced artwork. Research illustrations are not experimental evidence. NCAI interfaces describe collaborative team work. Book involvement is described as a contributor, not a cover-author credit. Institutional logos identify education and professional experience without implying endorsement. NeuroCare’s original domain currently redirects to SaveLife.AI; the button makes that destination explicit.

Scholar metrics are a supplied November 2026 snapshot, not a live feed. External profile services may require login or limit automated access. All essential assets and fonts are local. The Manrope font license is retained in assets/Manrope-OFL.txt.
